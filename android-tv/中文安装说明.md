# Poker Clock Pro Android TV

这是独立离线运行的 Android TV 德州升盲计时器。无需 Mac 服务端、网络或手机；规则保存在电视本机。电视全屏显示并用方向键和 OK 键控制比赛。

## 获得 APK

当前开发环境没有 Android SDK、Gradle 和 Java Runtime，因此没有生成本机 APK，也没有做真实电视验收。GitHub 构建工作流已设置在仓库根目录 `.github/workflows/apk.yml`。上传下方的 SDK 修复后，进入 **Actions（操作）→ 构建电视 APK**，下载 **PokerClockPro-APK** artifact，解压得到 `app-debug.apk`。这是 Debug 签名包，安装时需要电视允许文件管理器安装未知来源应用。

## 首次使用

安装后直接打开即可进入计时器。无需绑定服务器或输入 IP；规则保存在电视本机。

## 电视操作

方向键移动焦点，OK 确认。支持开始/暂停/恢复、上一等级、下一等级、重置本级、编辑比赛名称和盲注规则、添加或删除等级、恢复默认规则。编辑和切换等级会暂停计时；默认规则包括四级盲注和一个 10 分钟休息阶段。

比赛计时依据电视本机保存的结束时间计算；应用退出或电视重启后会从本机状态恢复，不依赖网络。

## 安装

把 APK 放进 U 盘，在电视文件管理器中打开并安装。若系统拦截，进入 **Settings（设置）→ Security / Install unknown apps（安全 / 安装未知应用）**，允许文件管理器安装 APK。

首次安装后请在目标电视上检查遥控器方向键、OK 确认、横屏显示、常亮和重启后的状态恢复。本环境无法替代真机验收。
