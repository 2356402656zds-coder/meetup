# Poker Clock Pro Android TV

这是连接 Mac 局域网服务端的 Android TV 客户端，不在电视本地保存或推进比赛计时。电视端全屏显示指定牌桌，并用方向键和 OK 键直接控制比赛。

## 获得 APK

当前开发环境没有 Android SDK、Gradle 和 Java Runtime，因此没有生成本机 APK，也没有做真实电视验收。手机可以把 `android-tv/` 上传到 GitHub，打开 Actions → 构建电视 APK → Run workflow，下载 `PokerTV-APK` 中的 `app-debug.apk`。这是 Debug 签名包，安装时需要电视允许文件管理器安装未知来源应用。

## 首次绑定

1. 先在 Mac 启动根目录的 Poker Clock Pro 服务端：`./scripts/start.sh`。
2. 查 Mac 的局域网 IP，例如 `192.168.1.23`。
3. 电视和 Mac 连接同一 Wi-Fi，打开 APK。
4. 电视输入 `http://192.168.1.23:8787` 和牌桌编号，例如 `A01`。
5. 保存后进入大屏。更换牌桌或服务端可在控制菜单中重新绑定。

## 电视操作

方向键移动焦点，OK 确认，Back 返回。支持开始/暂停/恢复、上一等级、下一等级、结束比赛、剩余人数增减、买入、Re-entry、Rebuy、Add-on，以及编辑当前等级 SB、BB、Ante 和分钟。结束比赛有二次确认；编辑当前等级会暂停并重置本级倒计时。

电视断网时计时仍由 Mac 服务端继续；重新连接后电视获取服务器最新快照。服务端重启也会根据 `ends_at` 和 `remaining_ms` 恢复，而不是把本级重置为完整时长。

## 验收清单

- 同时在 A01、A02 创建比赛，确认一张桌子的操作不影响另一张桌子。
- 开始、暂停、恢复并观察倒计时。
- 进入 Break、前后切换等级、结束比赛。
- 修改当前规则和人数，确认电脑后台和电视显示同步。
- 关闭电视网络后重新连接，确认比赛继续按照服务器时间运行。
- 重启 Mac 服务端，确认状态恢复。

APK 最终必须在目标电视型号上测试遥控器焦点、横屏、常亮、WebView 跨域访问和开机恢复；本环境无法替代这一步。
